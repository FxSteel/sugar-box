# The Sugar Box — sitio web

Landing + catálogo con cotizador que envía pedidos por WhatsApp. Next.js 16, Tailwind v4, shadcn/ReUI, desplegado en Dokploy.

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

Toda la documentación del proyecto (marca, arquitectura, SEO, despliegue) está en [`CLAUDE.md`](./CLAUDE.md).
